মাইক্রোসার্ভিস রানবুক
=====================

এই গাইডটি repository-র `microservices` folder-এর বর্তমান Compose ও environment configuration অনুযায়ী। Java 25, Maven এবং Docker Desktop প্রয়োজন। PostgreSQL, Redis, Kafka ও Schema Registry আলাদা local services হিসেবে চালু থাকতে হবে।

লোকাল dependency endpoint
-------------------------

- PostgreSQL: 5432
- Redis: 6379
- Kafka: local client 9092; Docker-host listener 29092
- Schema Registry: 8084
- API Gateway: host 8090 (container 8080)
- Config Server: 8888
- Eureka: 8761

কোনো real বা production credential repository-তে রাখবেন না।

Environment file তৈরি
---------------------

Repository root থেকে:

  Copy-Item microservices/.env.example microservices/.env
  notepad microservices/.env

সব placeholder নিজের local service-এর credential দিয়ে বদলান। `.env` Git-এ ignore করা আছে। নতুন JWT secret তৈরি করতে PowerShell-এ চালান:

  [Convert]::ToBase64String([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32))

একই `JWT_SECRET` auth-service ও API Gateway-কে দিতে হবে। আগে repository-তে থাকা কোনো credential অন্যত্র ব্যবহার হয়ে থাকলে সেটি rotate করুন; বর্তমান file থেকে মুছলেও পুরোনো Git commit-এ থাকতে পারে।

Build এবং application চালানো
----------------------------

Repository root থেকে:

  Set-Location .\microservices
  mvn clean package -DskipTests
  docker compose --env-file .env -f docker-compose.app.yml up --build -d
  docker compose --env-file .env -f docker-compose.app.yml ps

UI: http://localhost:8090/

Service health:

- Auth: http://localhost:8081/actuator/health
- Catalog: http://localhost:8082/actuator/health
- Inventory: http://localhost:8083/actuator/health
- Cart: http://localhost:8085/actuator/health
- Payment: http://localhost:8086/actuator/health
- Order: http://localhost:8087/actuator/health
- Notifications: http://localhost:8088/actuator/health

Log দেখুন:

  docker compose --env-file .env -f docker-compose.app.yml logs -f --tail 100

একটি service rebuild/restart:

  docker compose --env-file .env -f docker-compose.app.yml up -d --build --no-deps order-service

Application container বন্ধ করতে:

  docker compose --env-file .env -f docker-compose.app.yml down

Monitoring চালানো
-----------------

OTEL Collector application Compose-এর সঙ্গে শুরু হয়। Prometheus এবং Grafana আলাদা:

  docker compose --env-file .env -f docker-compose.monitoring.yml up -d

- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000
- Grafana password local `.env`-এর `GF_SECURITY_ADMIN_PASSWORD`; কোনো default password source-এ রাখা নেই।
- Prometheus-এর Status → Targets-এ scrape target `UP` কি না দেখুন।

বন্ধ করতে:

  docker compose --env-file .env -f docker-compose.monitoring.yml down

GUI monitoring controller
-------------------------

`monitoring-controller.ps1` শুধু loopback `127.0.0.1`-এ শোনে এবং `SHOPSPHERE_MONITORING_TOKEN` চায়। PowerShell-এ local token তৈরি করুন; সেটি কেবল নিজের GUI-তে দিন, source file-এ লিখবেন না:

  $bytes = [byte[]]::new(32)
  [System.Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
  $env:SHOPSPHERE_MONITORING_TOKEN = [Convert]::ToBase64String($bytes)
  $env:SHOPSPHERE_MONITORING_TOKEN
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\monitoring-controller.ps1

Controller চালু থাকা PowerShell window বন্ধ করলে controller-ও বন্ধ হবে।

Eclipse থেকে চালানো
-------------------

`microservices` folder-কে Existing Maven Project হিসেবে import করুন। PostgreSQL, Redis, Kafka, Schema Registry এবং Config Server আগে চালু করুন। Run configuration-এ local `.env`-এর মান environment variables হিসেবে দিন: `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME`, `SPRING_DATASOURCE_PASSWORD`, `JWT_SECRET`, `SPRING_REDIS_HOST`, `SPRING_REDIS_PORT`, `SPRING_KAFKA_BOOTSTRAP_SERVERS`, `SCHEMA_REGISTRY_URL`, এবং `CONFIG_SERVER_URL`। Auth service ও API Gateway-তে একই `JWT_SECRET` ব্যবহার করুন।

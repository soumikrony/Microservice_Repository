Spring Cloud Config Server
--------------------------

Central configuration রাখা আছে `config-repo` folder-এ। Docker-এ এটি app Compose
এর সঙ্গে চালু হয়। পরীক্ষা করুন:

  Invoke-WebRequest http://localhost:8888/actuator/health -UseBasicParsing
  Invoke-WebRequest http://localhost:8888/api-gateway/default -UseBasicParsing

প্রথম command-এ `UP` এবং দ্বিতীয় command-এ gateway configuration JSON পাওয়া উচিত।
সব client service-এ `spring.config.import` থাকার কারণে startup-এর সময় Config
Server থেকে properties নেওয়ার চেষ্টা করে; Config Server unavailable হলে local
`application.properties` fallback হিসেবে থাকে।

Redis version ও service চেক
---------------------------

Redis শুধু running কি না নয়, actual version-ও পরীক্ষা করুন:

  Get-Service Redis,Memurai -ErrorAction SilentlyContinue
  redis-cli -h 127.0.0.1 -p 6379 PING
  redis-cli -h 127.0.0.1 -p 6379 INFO server | findstr "redis_version memurai_version"

Expected:

  PONG
  redis_version:7.x

শুধু `Redis Running` দেখালেই Redis 7 নিশ্চিত হয় না। Redis 7-compatible runtime
চালু থাকলে `Memurai` Running এবং `redis_version`-এ 7.x দেখা উচিত। একই port-এ
পুরোনো Redis এবং Memurai একসাথে চালাবেন না।

Stop-Service Redis -Force
Start-Service Memurai

redis-cli -h 127.0.0.1 -p 6379 PING
redis-cli -h 127.0.0.1 -p 6379 INFO server | findstr redis_version

Prometheus, Grafana ও OpenTelemetry
------------------------------------

Prometheus এবং Grafana চালান:

  docker compose -f docker-compose.monitoring.yml up -d

তারপর microservices চালালে OTEL Collector-ও app Compose-এর সঙ্গে চালু হবে:

  docker compose -f docker-compose.app.yml up --build -d

Browser-এ দেখুন:

  Prometheus: http://localhost:9090
  Grafana: http://localhost:3000
  Grafana username: admin
  Grafana password: admin

Prometheus-এর `Status -> Targets` খুলে সব target-এ `UP` দেখুন। Metrics পরীক্ষা
করতে `http://localhost:8081/actuator/prometheus` অথবা
`http://localhost:8090/actuator/prometheus` খুলুন। Prometheus query box-এ
`http_server_requests_seconds_count` লিখে Execute করুন।

Grafana-এ প্রথমবার `Connections -> Data sources -> Add data source -> Prometheus`
নির্বাচন করে URL দিন `http://prometheus:9090`, তারপর `Save & test` চাপুন।
Dashboard query হিসেবে ব্যবহার করতে পারেন:

  rate(http_server_requests_seconds_count[1m])

OTEL flow:

  Spring Boot + Micrometer -> OTLP HTTP -> otel-collector:4318 -> Collector logs

Collector log দেখুন:

  docker logs -f shopsphere-otel-collector

Docker Compose-এ OTLP metrics ও traces enable করা আছে। Eclipse-এ defaultভাবে
এগুলো বন্ধ থাকে। Eclipse থেকে OTEL দেখতে চাইলে আগে Collector চালু করে Run
Configuration-এর Environment-এ দিন:

  OTEL_METRICS_EXPORT_ENABLED=true
  OTEL_TRACES_EXPORT_ENABLED=true
  OTEL_EXPORTER_OTLP_METRICS_ENDPOINT=http://localhost:4318/v1/metrics
  OTEL_EXPORTER_OTLP_TRACES_ENDPOINT=http://localhost:4318/v1/traces

Monitoring বন্ধ করতে:

  docker compose -f docker-compose.monitoring.yml down

GUI থেকে Monitoring control
----------------------------

GUI switch দিয়ে Prometheus, Grafana এবং OTEL Collector সত্যি start/stop করতে
একটি নিরাপদ host-side controller চালাতে হবে। এটি শুধু `127.0.0.1:8767`-এ
শুনবে এবং token ছাড়া কোনো command গ্রহণ করবে না। Administrator PowerShell
প্রয়োজন নেই, তবে Docker Desktop চালু থাকতে হবে।

PowerShell window-এ চালান:

  Set-Location 'C:\Softwares\Self Project\microservices'
  $env:SHOPSPHERE_MONITORING_TOKEN='change-this-to-a-long-random-token'
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\monitoring-controller.ps1

`running scripts is disabled` error এলে এই `Bypass` command-টিই ব্যবহার করুন।
এটি Windows-এর স্থায়ী execution policy পরিবর্তন করে না। চাইলে শুধু নিজের user
account-এর জন্য একবার অনুমতি দিতে পারেন:

  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

তারপর GUI খুলে Monitoring Controls section-এ একই token লিখুন। Switch ON করলে
controller Docker Compose দিয়ে service চালু করবে; OFF করলে সেই container stop
করবে। Browser বন্ধ করলে controller বন্ধ হয় না; controller বন্ধ করতে তার
PowerShell window-এ `Ctrl+C` চাপুন।

নিরাপত্তা: controller-টি কেবল loopback address-এ bind করা এবং token-protected।
Token কখনও source code বা public network-এ রাখবেন না।

Eureka Service Discovery
========================

এই project-এ Eureka Server service registry হিসেবে কাজ করে। সব Spring Boot
service startup-এর সময় নিজের নাম ও address Eureka-তে register করে। Gateway
business request-এর জন্য lb://service-name ব্যবহার করে Eureka থেকে service
instance খুঁজে নেয়।

Docker Compose-এ Eureka চালু/পরীক্ষা:
  docker compose -f docker-compose.app.yml up -d --build eureka-server
  Invoke-WebRequest http://localhost:8761/actuator/health -UseBasicParsing
  Start-Process http://localhost:8761

সব service Eureka-সহ চালু করুন:
  docker compose -f docker-compose.app.yml up -d --build

Registration দেখুন:
  (Invoke-WebRequest http://localhost:8761/eureka/apps -Headers @{Accept='application/json'} -UseBasicParsing).Content

উপরের output-এ AUTH-SERVICE, CATALOG-SERVICE, INVENTORY-SERVICE, CART-SERVICE,
PAYMENT-SERVICE, ORDER-SERVICE, NOTIFICATIONS-SERVICE এবং API-GATEWAY দেখা উচিত।
Eureka বন্ধ করতে পুরো Compose application বন্ধ করুন:
  docker compose -f docker-compose.app.yml down
